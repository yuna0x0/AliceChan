# Alice Chan (Uniform ver.)

Alice Chan (Uniform ver.), a VRoid Studio character, as a VRM 1.0 avatar for Unity.

Requires Unity 2022.3 or newer and UniVRM 0.131.2 or newer (`com.vrmc.vrm`). UniVRM is not
declared as a package dependency, so install it first.

The package contains `Models/AliceChan.vrm`, which UniVRM imports, and `Models/AliceChan.prefab`,
a prefab variant of the imported model. A demo scene is available as a sample in the Package
Manager window.

Installation, other download formats and the licence are described in the
[repository README](https://github.com/yuna0x0/AliceChan#readme).
